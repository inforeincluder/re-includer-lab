# Como revisar apoios de forma colaborativa

Um apoio não deve ser mantido apenas porque parece adequado para um adulto ou porque funcionou em outra situação. A experiência da pessoa que o utiliza é parte central da avaliação.

## Roteiro de revisão

1. Defina uma barreira concreta que a pessoa deseja reduzir.
2. Combine qual apoio será testado, em qual situação e por quanto tempo será razoável observar.
3. Explique que o teste pode ser interrompido ou modificado.
4. Registre o que aconteceu, sem atribuir intenção.
5. Pergunte à pessoa como foi usar o apoio.
6. Decidam juntos se devem manter, adaptar ou interromper.

## Ficha de acompanhamento

| Pergunta | Registro |
|---|---|
| O que queríamos facilitar? |  |
| Qual apoio foi testado e em qual contexto? |  |
| O que mudou na participação ou na tarefa? |  |
| Como a pessoa avaliou o apoio? |  |
| Houve desconforto, exposição ou trabalho extra? |  |
| O apoio aumentou autonomia? |  |
| Decisão: manter, adaptar ou interromper? |  |

## Perguntas para a própria pessoa

- Isso ajudou no que você queria fazer?
- Teve alguma parte incômoda ou difícil?
- Você gostaria de continuar usando?
- O que mudaria?
- Existe outra forma que prefere experimentar?

Adapte as perguntas à comunicação da pessoa. Ela pode responder por fala, escrita, símbolos, comunicação alternativa ou outro meio acessível.

## Cuidados

Não transforme o registro em vigilância ou avaliação de obediência. Não use uma experiência isolada para concluir que a pessoa não consegue realizar uma atividade. Se o apoio não funcionar, revise a estratégia e o ambiente antes de atribuir a dificuldade à pessoa.
