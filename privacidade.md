# Privacidade

O 2e Lab Brasil busca minimizar a coleta de dados pessoais.

## Navegação

O site é hospedado no GitHub Pages. A infraestrutura de hospedagem pode processar dados técnicos de acesso conforme as políticas do provedor. Consulte também a [política de privacidade do GitHub](https://docs.github.com/pt/site-policy/privacy-policies/github-privacy-statement).

No momento, esta página não anuncia formulário próprio de cadastro, área de membros ou coleta direta de dados sensíveis pelo site.

## Links externos e afiliados

Ao acessar links de terceiros, você passa a estar sujeito às políticas e práticas desses serviços. Links afiliados, quando existentes, serão identificados conforme a [política de transparência comercial](/transparencia-comercial/).

## Dados sensíveis

Não envie por comentários públicos, e-mails ou outros canais informações médicas, diagnósticos, documentos escolares ou dados identificáveis de crianças. O portal não precisa desses dados para oferecer seus conteúdos públicos.

## Alterações

Esta política poderá ser atualizada quando novas funcionalidades, ferramentas de análise, publicidade ou formas de contato forem incorporadas. A versão vigente será mantida nesta página.
